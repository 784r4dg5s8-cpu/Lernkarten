## VL 1 · Einführung: Psychologische Diagnostik, Relevanz & Anwendungsfelder
!Definiere Psychologische Diagnostik nach Schmidt-Atzert, Krumm & Amelang (2021). || Teildisziplin der Psychologie zur Beantwortung von Fragestellungen zu Beschreibung, Klassifikation, Erklärung oder Vorhersage menschlichen Verhaltens und Erlebens // gezielte Erhebung und Interpretation von Informationen über Verhalten, Erleben und relevante Bedingungen // geleitet von psychologischem Wissen, mit wissenschaftlichen Methoden.
Status- vs. Veränderungsdiagnostik? || Statusdiagnostik: Eingangsdiagnostik, beschreibt den momentanen Zustand, stellt Veränderungsnotwendigkeit fest // Veränderungsdiagnostik: Verlaufs-/Prozessdiagnostik, stellt den Erfolg von Interventionen fest.
Selektion vs. Modifikation? || Selektion: Auswahl von Personen oder Bedingungen (z. B. neue Lehrkräfte einstellen) // Modifikation: Veränderung von Person oder Umwelt, sodass die Passung besser wird (z. B. Arbeitsbedingungen nach Krankheit anpassen).
!Definiere Modifikationsdiagnostik und grenze sie von Veränderungsdiagnostik ab. || Modifikation: Person/Umwelt (Verhalten/Bedingungen) wird verändert, damit die Passung besser wird – Gegenpol zur Selektion // Veränderungsdiagnostik: misst den Verlauf und Erfolg einer Intervention – Gegenpol zur Statusdiagnostik.
Nenne die Ziele von Diagnostik. || Konkrete Fragestellungen beantworten // Zustand beschreiben (Status) // Selektion vs. Modifikation // Ereignisse bzw. aufrechterhaltende Bedingungen erklären // Verhalten vorhersagen // Notwendigkeit und Erfolg von Interventionen feststellen.
Wie gut lässt sich Verhalten durch einen einzelnen Prädiktor vorhersagen? || Nur bedingt – realistisch ca. 25 % Verhaltensaufklärung.
!Warum hat Psychologische Diagnostik herausragende Bedeutung für praktisch tätige Psycholog:innen (Roth & Herzberg, 2008)? || Befragung (N = 398): im Schnitt 27 % der Tätigkeit ist Diagnostik // Verkehrs-/forensische Psychologie 44 %, A&O 30 %, pädagogisch 29 %, klinisch 24 % – große Streuung // Grundlage für Interventionsentscheidungen.
Zusammenhang: Wie hängen Fragestellung, diagnostische Strategien und Ziele zusammen? || Ausgangspunkt ist immer eine konkrete Fragestellung (Beschreibung, Klassifikation, Erklärung, Vorhersage) → sie bestimmt die Strategie: Status vs. Veränderung, Selektion vs. Modifikation → daraus folgt das Ziel, z. B. auswählen, anpassen, Interventionsbedarf oder -erfolg feststellen.
!Fall: Ein Unternehmen wählt aus 60 Bewerbungen 5 Azubis aus. Bei einer Mitarbeiterin wird nach einem Bandscheibenvorfall der Arbeitsplatz angepasst; ein halbes Jahr später prüft man, ob die Anpassung geholfen hat. Ordne die diagnostischen Strategien zu. || Azubi-Auswahl: Selektion (Personen auswählen) als Statusdiagnostik // Arbeitsplatzanpassung: Modifikation – Bedingungen werden verändert, damit die Passung besser wird // Prüfung nach einem halben Jahr: Veränderungsdiagnostik (Erfolg der Intervention).
Fall: Eine Personalleiterin will künftige Arbeitsleistung allein mit einem Intelligenztest „sicher“ vorhersagen. Was entgegnest du? || Ein einzelner Prädiktor erklärt realistisch nur ca. 25 % des Verhaltens // Vorhersage ist ein legitimes Ziel von Diagnostik, bleibt aber eine Wahrscheinlichkeitsaussage // besser mehrere Informationsquellen kombinieren.
Fall: Eine Therapeutin lässt vor Therapiebeginn und nach 12 Sitzungen denselben Depressionsfragebogen ausfüllen. Welche Diagnostik steckt jeweils dahinter? || Vor Beginn: Statusdiagnostik – aktueller Zustand, Behandlungsnotwendigkeit // nach 12 Sitzungen: Veränderungsdiagnostik – Verlauf und Erfolg der Intervention.
## VL 2 · Modellannahmen, diagnostischer Prozess & Verfahrensarten
Trait vs. State? || Trait: relativ breite, zeitlich stabile Verhaltenseigenschaft, die konsistent über Situationen auftritt // State: nicht stabiler, situationsabhängiger Zustand (z. B. Angst, Müdigkeit, Erregtheit) – vom Eigenschaftsmodell ausgeschlossen.
Nenne die Grundannahmen des eigenschaftstheoretischen Ansatzes. || Eigenschaften sind hypothetische Konstrukte, nicht direkt beobachtbar → vom Verhalten wird auf Eigenschaften geschlossen // Verhaltensweisen sind Indikatoren und müssen repräsentativ sein // Prüfung mit Verfahren für stabile Merkmale (z. B. Persönlichkeitsfragebögen).
Nenne die Grundannahmen des verhaltenstheoretischen Ansatzes. || Verhalten ist Funktion der Situation und früher erfahrener Konsequenzen // erlernt und damit veränderbar // von zurückliegendem auf zukünftiges Verhalten schließen // Prüfung situativ (Beobachtung, Verhaltensanalyse).
!Zusammenhang: Erkläre eigenschafts- bzw. verhaltenstheoretisch, warum sich eine Studierende in Vorlesungen zurückhaltend verhält. || Eigenschaftstheoretisch: Indikator einer stabilen, situationsübergreifenden Eigenschaft // verhaltenstheoretisch: gelerntes Verhalten aufgrund früherer Konsequenzen in ähnlichen Situationen, veränderbar // Aggregation: beide ergänzen sich.
!Erkläre den diagnostischen Prozess nach Ziegler & Bühner (2012) am Beispiel „Liegt bei meinem Kind eine Hochbegabung vor?“ || Fragestellung → Hypothesen/Teilfragen + Entscheidungskriterien (IQ > 130 zur Altersnorm?) → Operationalisierung (IQ-Test, Schulnoten) → Durchführung (Untersuchungsplan) → Auswertung → Integration (Hypothese annehmen/ablehnen, ggf. weitere Untersuchung).
!Nenne die drei großen Gruppen diagnostischer Verfahren. || Leistungstests // Persönlichkeitsfragebögen // projektive Verfahren // daneben: Verhaltensbeobachtung/-beurteilung, diagnostisches Interview, Gruppendiagnostik.
Was sind Leistungstests? Speed- vs. Powertest? || Testleistung als Arbeit pro Zeit; Indikator für Fähigkeit, Fertigkeit oder Wissen (z. B. Intelligenz-, Konzentrationstests) // Speedtest: Zeit vorgegeben, Schnelligkeit zählt // Powertest: ohne Zeitvorgabe.
!Ist es sinnvoll, einen Leistungstest zu wiederholen, weil sich ein Proband unterschätzt fühlt? || Retest-Effekt: einmalige Wiederholung +3,3 Standardwertpunkte (Scharfen et al., 2018) // Effekt steigt mit Wiederholungen, kleiner bei Parallelform, am größten bei Intelligenz (Hausknecht et al., 2007) // höherer Wert ≠ höhere Fähigkeit → wenn, dann Parallelform.
Was kennzeichnet Persönlichkeitsfragebögen? || Erfassen Persönlichkeit über Eigenschaften (meist Big Five) per standardisierter Selbsteinschätzung, Vergleich über Normen // Problem: Verfälschbarkeit // Gegenmaßnahmen: Instruktion zur Ehrlichkeit, Forced-Choice, Kontrollskala, Fremdbeurteilung.
Was kennzeichnet projektive Verfahren? || Aus Reaktionen auf das Testmaterial in standardisierter Situation wird auf Persönlichkeit geschlossen (Projektion eigener Eigenschaften); für Testpersonen undurchschaubar // z. B. TAT, Rorschach // umstritten: fehlende Gütekriterien („psychometrischer Albtraum“).
!Nenne die Gütekriterien diagnostischer Verfahren und die Teilaspekte der Objektivität. || Objektivität: Durchführungs-, Auswertungs-, Interpretationsobjektivität // Reliabilität // Validität.
!In welchen Rollen ist ein:e Diagnostiker:in tätig, z. B. bei Verdacht auf Lese-Rechtschreib-Schwäche? || Verstehende:r: Fragestellung und Konstrukt klären // Expert:in: geeignete, qualitativ hochwertige Verfahren auswählen // Präsentierende:r: Ergebnisse verständlich übermitteln.
Zusammenhang: Wie hängen Rollen, Verfahren und Gütekriterien in der Prozess- und Ergebnisverantwortung zusammen? || Verstehende:r klärt Fragestellung und Konstrukt (z. B. Intelligenz) → Expert:in bildet es mit geeigneten Messmethoden von geprüfter Güte (Objektivität, Reliabilität, Validität) in einem empirischen Wert ab → Präsentierende:r übermittelt das Ergebnis.
!Fall: Eine Lehrerin fragt, ob bei Tim (8) eine Lese-Rechtschreib-Schwäche vorliegt. Beschreibe den diagnostischen Prozess nach Ziegler & Bühner (2012). || Fragestellung klären // Hypothesen/Teilfragen bilden (LRS? Alternativen wie Seh- oder Hörprobleme, allgemeine Lernschwierigkeiten) und Entscheidungskriterien festlegen // Operationalisierung: standardisierter Lese-Rechtschreib-Test, Intelligenztest, Schulnoten, Gespräch mit Eltern und Lehrkraft // Durchführung nach Untersuchungsplan und Auswertung (Normvergleich) // Integration: Hypothesen annehmen oder ablehnen, ggf. weitere Untersuchung, Ergebnis verständlich zurückmelden.
!Fall: Eine Probandin füllt direkt vor ihrer Führerscheinprüfung einen Angstfragebogen aus und hat sehr hohe Werte. Darfst du auf eine ängstliche Persönlichkeit schließen? || Nein: Die Messung in einer akuten Stresssituation erfasst eher einen State // ein Trait ist zeitlich stabil und situationsübergreifend → mehrere Situationen bzw. Zeitpunkte oder ein Trait-Verfahren nötig // verhaltenstheoretisch ist die Angst hier situativ gut erklärbar.
Fall: Wähle ein Verfahren: a) Konzentrationsfähigkeit von Fluglotsen-Bewerber:innen, b) Big-Five-Profil für ein Coaching, c) Rorschach-Test für eine Personalauswahl. || a) Leistungstest, z. B. Speedtest (Arbeit pro Zeit) // b) Persönlichkeitsfragebogen mit Normvergleich // c) projektives Verfahren – wegen fehlender Gütekriterien für Auswahlentscheidungen ungeeignet.
!Fall: Im Assessment-Center haben alle Bewerber:innen im Persönlichkeitsfragebogen auffällig „perfekte“ Werte. Was ist das Problem und was hilft? || Verfälschbarkeit: sozial erwünschtes Antworten, besonders stark bei Selektion // Gegenmaßnahmen: Instruktion zur Ehrlichkeit // Forced-Choice-Format // Kontrollskala // Fremdbeurteilung ergänzen.
!Fall: Zwei Testleiterinnen geben unterschiedliche Instruktionen, zählen bei denselben Antwortbögen verschieden viele Punkte, und bei gleichem Punktwert zieht eine dritte andere Schlüsse. Welche Objektivität ist jeweils verletzt? || Unterschiedliche Instruktion → Durchführungsobjektivität // unterschiedliche Punkte → Auswertungsobjektivität // unterschiedliche Schlüsse bei gleichem Wert → Interpretationsobjektivität // Abhilfe: standardisierte Instruktion, feste Auswertungsregeln, Normen.
Fall: Ein Proband erreicht im Intelligenztest einen Wert, der ihm zu niedrig vorkommt, und will den Test wiederholen. Du hast nur die gleiche Testform. Was tust du? || Keine direkte Wiederholung: Retest-Effekt ca. +3,3 Standardwertpunkte, bei Intelligenz am größten // der höhere Wert würde Übung abbilden, keine höhere Fähigkeit // wenn wiederholt, dann mit Parallelform und Abstand.
