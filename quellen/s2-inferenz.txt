## Grundlagen & Inferenzlogik
Was ist die Aufgabe der Inferenzstatistik? || Abschätzen, mit welcher Sicherheit von beobachteten Ereignissen (Stichprobe) auf allgemeine Gesetzmäßigkeiten (Population) geschlossen werden kann.
!Welche 5 Schritte hat ein Signifikanztest? || 1. Voraussetzungen prüfen, Test wählen // 2. Hypothesen aufstellen (gerichtet/ungerichtet) // 3. Prüfgröße berechnen // 4. Vergleich mit kritischem Wert bzw. p-Wert // 5. Schlussfolgerung ziehen.
Welche Konventionen gelten für Signifikanzniveaus? || p > .05 nicht signifikant // p ≤ .05 signifikant // p ≤ .01 hochsignifikant. Die Irrtumswahrscheinlichkeit der Signifikanzaussage beträgt α·100 %.
!Wann testet man einseitig, wann zweiseitig? || Zweiseitig: Fragestellung ohne Richtung („Unterschied“, „Zusammenhang“). // Einseitig: Richtung genannt („reduziert“, „höher als“, „positiver Einfluss“).
Wie lautet die Entscheidungsregel beim kritischen Wert? || |Prüfgröße_emp| > kritischer Wert → signifikant, H0 verwerfen; sonst H0 beibehalten. Kritischer Wert passend zu df, α und ein-/zweiseitig ablesen.
Was ist die Teststärke (Power)? || Die Wahrscheinlichkeit, dass ein Test zugunsten einer spezifischen H1 entscheidet, falls diese gilt: Power = 1 − β (β = Fehler 2. Art, α = Fehler 1. Art).
!Zusammenhang: Welche Tests sieht die Testübersicht für Unterschiedshypothesen vor? || Unabhängig, 2 Gruppen: t-Test (intervall) / Mann-Whitney-U (ordinal) / χ² (nominal); > 2: ANOVA. // Abhängig, 2: t-Test / Wilcoxon / McNemar; > 2: rmANOVA.
Zusammenhang: Welche Verfahren sieht die Testübersicht für Zusammenhangshypothesen vor? || UV/AV unklar: Pearson r (metrisch), Spearman rs/Kendalls τ (ordinal), χ²/Cramérs V/Phi (nominal). // UV → AV: einfache Regression; mehrere UVs: multiple (AV metrisch), ordinale, logistische (AV nominal) Regression.

## t-Tests
!Wann verwendet man den t-Test für unabhängige bzw. abhängige Stichproben? || Unterschied zweier Mittelwerte bei intervallskalierter AV. // Unabhängig: zwei verschiedene Gruppen (Gamer vs. Nicht-Gamer). // Abhängig: dieselbe Stichprobe zweimal gemessen (vorher/nachher).
Formel: t-Test für unabhängige Stichproben? || t = Mittelwertsdifferenz / Standardfehler der Differenz; df = n1 + n2 − 2. // H0: μ1 = μ2; H1: μ1 ≠ μ2 (ungerichtet).
Formel: t-Test für abhängige Stichproben? || Differenz d je Person bilden; t = d̄ / SE mit SE = s_d / √n; df = n − 1.
!Rechenweg t-Test (Schritte)? || 1. Design (un-/abhängig) // 2. ein-/zweiseitig // 3. H0/H1 // 4. SE, Differenz, t // 5. df, t_krit ablesen, vergleichen // 6. Laiensatz. Bsp. Gamer (α = 1 %): t = 0,67 < 3,106 (df = 11) → kein Unterschied.
Welche Voraussetzungen hat der t-Test? || Intervallskalierte AV, Normalverteilung der AV; beim unabhängigen t-Test zusätzlich Varianzhomogenität (bei ungleichen Gruppengrößen kritischer). Bei starker Verletzung: nichtparametrischer Test.
Zusammenhang: Wie hängen t-Test, ANOVA und Rangtests zusammen? || ANOVA = Erweiterung des t-Tests auf mehr als zwei Gruppen (abhängig: rmANOVA). // Ordinale Pendants: Mann-Whitney-U (unabhängig), Wilcoxon (abhängig).

## Korrelation & Fisher-Z-Test
Was misst die Produkt-Moment-Korrelation r und wann verwendet man sie? || Stärke und Richtung eines linearen Zusammenhangs zweier metrischer Variablen (UV/AV unklar); −1 bis +1, Vorzeichen = Richtung, Betrag = Stärke; ausreißeranfällig.
!Formel: Kovarianz und Pearson-r? || s_xy = (1/n)·Σ(xi − x̄)(yi − ȳ) // r = s_xy / (s_x · s_y). Die Kovarianz hängt von der Skalierung ab, r ist standardisiert und vergleichbar.
Faustregeln nach Cohen (1988) für r? || |r| < .10 kein // < .30 kleiner // < .50 mittlerer // ≥ .50 hoher Zusammenhang.
!Rechenweg Signifikanztest der Korrelation? || 1. Kovarianz → r // 2. t = r·√(n − 2) / √(1 − r²), df = n − 2 // 3. t_krit vergleichen // 4. Richtung/Stärke/Signifikanz berichten. Bsp. Smartphone/Schlaf: r = −0,85; t = −3,25 → signifikant.
!Wann und wie verwendet man den Fisher-Z-Test? || Vergleich zweier Korrelationen aus unabhängigen Stichproben: r1, r2 in Fishers Z transformieren; z = (Z1 − Z2) / √(1/(n1 − 3) + 1/(n2 − 3)); z_krit 5 % zweiseitig ±1,96.
Wann verwendet man punktbiseriale, biseriale und tetrachorische Korrelation? || Punktbiserial: X echt dichotom, Y intervallskaliert. // Biserial: eine Variable künstlich dichotomisiert. // Tetrachorisch: beide künstlich dichotomisiert (2×2-Tafel).
Zusammenhang: Darf man aus einer Korrelation auf Kausalität schließen? || Nein – X → Y, Y → X oder Drittvariable möglich. Kausalität braucht: Kovariation, zeitliche Vorordnung der Ursache, Ausschluss anderer Erklärungen, Generalisierbarkeit.

## Varianzanalyse – Grundlagen
Was ist das Ziel der Varianzanalyse (ANOVA)? || Einfluss einer oder mehrerer UVn (Faktoren mit Stufen) auf eine intervallskalierte AV prüfen: Mittelwertsunterschiede werden über den Vergleich von Treatment- und Fehlerstreuung aufgedeckt.
Welche Arten der Varianzanalyse gibt es? || Einfaktoriell (1 UV) // mehrfaktoriell (≥ 2 UVs) // MANOVA (≥ 2 AVs) // mit Messwiederholung (abhängige Stichproben) // ANCOVA (mit Kovariablen).
Zusammenhang: Wie hängen Treatmentstreuung, Fehlerstreuung und F zusammen? || Ohne Treatmenteffekt entsteht die Streuung der Stufenmittel nur aus Fehlerstreuung (F ≈ 1). Ist die Treatmentstreuung deutlich größer, gibt es systematische Mittelwertsunterschiede.
Welche Voraussetzungen hat die einfaktorielle ANOVA und wie prüft man sie? || Intervallskalierte AV // unabhängige Gruppen/Residuen (begründet angenommen) // Normalverteilung (Kolmogoroff-Smirnov) // Varianzhomogenität (Bartlett, Levene).
Wie robust ist die ANOVA, und was gilt für die Stichprobengröße? || Verletzte Unabhängigkeit erhöht α; Normalverteilung bei n > 30 robust; Varianzhomogenität robust bei gleich großen Gruppen. // Zellen ≥ 10 und annähernd gleich groß.

## Einfaktorielle ANOVA: Rechnen & Post-hoc
Welche Hypothesen prüft die einfaktorielle ANOVA? || H0: μ1 = μ2 = … = μJ. // H1: μi ≠ μj für mindestens ein Paar – welche Gruppen sich unterscheiden, sagt der F-Test nicht.
!Formel: QS-Zerlegung, F und df der einfaktoriellen ANOVA? || QS_tot = QS_zw + QS_inn // MQS = QS / df // F = MQS_zw / MQS_inn // df_zw = J − 1; df_inn = n − J (J = Stufen, n = Gesamt-N).
!Rechenweg einfaktorielle ANOVA (Klausurschema)? || 1. PopVar_Treat = QS_Treat/df // 2. PopVar_Fehler = QS_Fehler/df // 3. F = Quotient // 4. F_krit(df1, df2) vergleichen // 5. η². Bsp. Feedback: F = 104/6,67 = 15,59 > 4,256 → signifikant.
!Wie berechnet man η² in der einfaktoriellen ANOVA? || η² = QS_Treat / QS_tot (aufgeklärt); QS_Fehler / QS_tot (unaufgeklärt); ·100 = %. Bsp. Pausengestaltung: 150/270 ≈ .56 (Musterlösung nennt abweichend .2).
!Warum braucht man Post-hoc-Tests, und was ist α-Fehler-Kumulierung? || F zeigt nur, dass sich mindestens zwei Stufen unterscheiden; Post-hoc-Paarvergleiche zeigen welche. Viele Vergleiche erhöhen α → Bonferroni: α / Anzahl Vergleiche (.05/3 = .0167).
A-priori-Kontraste vs. Scheffé-Test? || A-priori: Hypothesen vor der Untersuchung, F = D² / ŝ²_D mit df = 1. // Scheffé (a posteriori, nach Ansehen der Daten): F_corr = F / df_Zähler.
Zusammenhang: Wie berichtet man eine ANOVA mit F, Post-hoc und η²? || F-Test: ob Unterschied („F(2, 9) = 15.59; p < .05“) // Post-hoc: welche Gruppen (Video > schriftlich, > mündlich) // η²: wie viel Varianz die Gruppenzugehörigkeit erklärt (78 %).

## Mehrfaktorielle ANOVA & Interaktion
Welche drei Fragen beantwortet die zweifaktorielle ANOVA? || Haupteffekt A // Haupteffekt B // Interaktion A×B: Wirkt eine Kombination der Stufen anders als additiv erwartet?
Formel: lineares Modell der zweifaktoriellen ANOVA? || x_ijk = μ + a_j + b_k + a_j·b_k + e_ijk // Messwert = Populationsmittel + Effekt A + Effekt B + Interaktion + Fehler.
Rechenweg zweifaktorielle ANOVA (p, q Stufen, n pro Zelle)? || QS_tot = QS_A + QS_B + QS_A×B + QS_Fehler // df: p − 1; q − 1; (p − 1)(q − 1); p·q·(n − 1) // je Effekt F = Var_Effekt / Var_Fehler, p prüfen.
Wie ist die Interaktion formal definiert? || Nicht-additiver Teil des gemeinsamen Effekts: Abweichung des Zellmittels vom additiv erwarteten Wert Āj + B̄k − G.
!Wie liest man Interaktionsplots und welche Interaktionsarten gibt es? || Parallele Linien = keine Interaktion. // Ordinal: Linien schneiden sich in keinem Plot. // Disordinal: in beiden Plots. // Hybrid: nur im Gegenplot.
Zusammenhang: Wie hängen Haupteffekte und Interaktion zusammen? || Haupteffekte beschreiben Stufenmittel gemittelt über den anderen Faktor; eine signifikante Interaktion zeigt, dass der Effekt von A von der Stufe von B abhängt – Haupteffekte dann nur eingeschränkt interpretieren.

## rmANOVA (Messwiederholung)
!Wann verwendet man eine rmANOVA? || Wenn dieselben Personen in mehr als zwei Treatmentstufen/Messzeitpunkten gemessen werden und die AV intervallskaliert ist (z. B. 3 Messzeitpunkte, dieselben 6 Personen).
Vor- und Nachteile der rmANOVA? || Vorteil: Personenunterschiede werden herausgerechnet → kleinere Fehlervarianz, schärferer Test. // Nachteil: anspruchsvollere Voraussetzungen; fällt eine Person aus, fehlen alle Stufen.
Welche Voraussetzungen hat die rmANOVA? || Abhängige Beobachtungen; Fehler normalverteilt; Sphärizität (gleiche Varianzen der Stufendifferenzen). Verletzung → Test zu progressiv; Prüfung: Mauchly; Korrektur: Greenhouse-Geisser/Huynh-Feldt.
!Wie wird die Quadratsumme in der rmANOVA zerlegt? || QS_tot = QS_zwischen (Personen, uninteressant) + QS_innerhalb // QS_innerhalb = QS_Treat + QS_Fehler (Residual).
Formel: F und df der rmANOVA (n Personen, p Stufen)? || F = (QS_Treat / df_Treat) / (QS_Fehler / df_Fehler) // df_Treat = p − 1 // df_Fehler = (n − 1)·(p − 1).
!Rechenweg rmANOVA mit partiellem η²? || PopVar = QS/df für Treat und Fehler → F → F_krit vergleichen → part. η² = QS_Treat / QS_innerhalb. Bsp. Lauftraining: F = 60/4 = 15 > 4,103; η² = 120/160 = .75.
Zusammenhang: Einfaktorielle ANOVA vs. rmANOVA? || Unabhängig: Fehler = gesamte Streuung innerhalb der Gruppen; η² an QS_tot. // rmANOVA: Personenstreuung abgezogen, Fehler = Residual; partielles η² an QS_innerhalb.

## Einfache lineare Regression
Wozu dient die einfache lineare Regression? || Sie prüft, ob ein Prädiktor x ein Kriterium y beeinflusst, und sagt y über die Regressionsgleichung vorher. Keine Kausalanalyse: Was x und y ist, wird inhaltlich vorab festgelegt.
Regressionsgleichung und Kleinste-Quadrate-Kriterium? || ŷ = a + b·x; b = Veränderung von y pro Einheit x; a = y bei x = 0. // KQ: Gerade, bei der Σ(yi − ŷi)² minimal ist.
!Formel: Steigung b und Achsenabschnitt a? || b = s_xy / s_x² = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)² = r·(s_y / s_x) // a = ȳ − b·x̄.
Formel: Signifikanztest der Steigung? || H0: β = 0 (gerichtet β ≤ 0) // s_e = √(Σe² / (n − 2)) // s_b = s_e / √QS_x // t = b / s_b, df = n − 2.
!Rechenweg Regression (Schritte)? || 1. b, a → Gleichung // 2. s_e, s_b, t // 3. t_krit vergleichen // 4. R² nach Cohen. Bsp. Beratungstermine: ŷ = 22,4 + 10,4·x; t = 22,61 > 3,18; R² = .994 → pro Termin +10,4 Punkte.
Was ist der Determinationskoeffizient R²? || Anteil der Varianz von y, der durch das Modell erklärt wird (·100 = %). Einfache Regression: R² = r²_xy.
Welche Voraussetzungen hat der Regressionstest? || Linearität, Homoskedastizität, normalverteilte und unabhängige Fehler. Ausreißer nicht nur über Residuen prüfen, sondern mit Einflussstatistiken (Cook-Distanz > 1).
Zusammenhang: Korrelation vs. Regression? || Korrelation: ungerichteter Zusammenhang, standardisiert. // Regression: gerichtete Vorhersage y aus x in Originaleinheiten. // Verknüpft über b = r·(s_y / s_x) und R² = r².

## Multiple Regression
Was ist die Grundidee der multiplen Regression? || Ein Kriterium wird aus mehreren Prädiktoren vorhergesagt: ŷ = b0 + b1·x1 + … + bk·xk (KQ-Schätzung). Jedes Gewicht zeigt den Beitrag eines Prädiktors bei Konstanthaltung der übrigen.
!b- vs. β-Gewicht? || b: unstandardisiert, in Originaleinheiten (absolute Information). // β: standardisiert, vergleichbar – zeigt den relativ wichtigsten Prädiktor. // b_i = β_i · SD_y / SD_xi.
Was sind der multiple Korrelationskoeffizient R und das adjustierte R²? || R: Korrelation zwischen gemessenen y und vorhergesagten ŷ. // Adjustiertes R²: korrigiert, dass R² mit jedem zusätzlichen Prädiktor steigt (Überschätzung).
Faustregeln nach Cohen für R²? || < .01 keine // < .10 kleine // < .25 mittlere // ≥ .25 hohe Varianzaufklärung (quadrierte r-Regeln).
Zusammenhang: Was ändert sich, wenn Prädiktoren unabhängig bzw. korreliert sind? || Unabhängig: β = Kriteriumskorrelationen, R² = Σβ². // Korreliert: Gewichte ändern sich in Höhe und Vorzeichen; gemeinsame Varianz wird nur einmal gezählt.
Was ist die Nützlichkeit eines Prädiktors? || U_j = R²(mit x_j) − R²(ohne x_j) – nur von x_j aufgeklärte Varianz (inkrementelle Validität), per F-Test geprüft; Basis der datengesteuerten Auswahl (vorwärts, rückwärts, schrittweise).
Was ist Multikollinearität und wie prüft man sie? || Die Kriteriumskovarianz eines Prädiktors ist fast vollständig in anderen Prädiktoren enthalten – vermeiden. Prüfen: Prädiktorkorrelationen < .7, VIF < 10, Toleranz > .10.
Was ist eine Suppressorvariable? || Eine Variable, die kaum mit dem Kriterium, aber mit einem anderen Prädiktor korreliert und dort irrelevante Varianz bindet; dadurch steigt die Vorhersage (U_xj > r²_xjy).
Welche Voraussetzungen hat die multiple Regression? || Linearität und Homoskedastizität (Residualplot ohne Muster), normalverteilte und unabhängige Residuen (Durbin-Watson ≈ 2), keine Multikollinearität, keine starken Ausreißer, 10–25 Personen pro Prädiktor.
Wie interpretiert man den Output einer multiplen Regression? || F-Test: Erklärt das Modell signifikant Varianz (R² > 0)? // Pro Prädiktor: b, β, p. Bsp.: Führungsqualität β = .52 wichtiger als WLB β = .29 (beide p < .001).

## Moderation & Mediation
!Was ist eine Moderation? || Der Effekt der UV auf die AV hängt von einer Drittvariable (Moderator) ab, die ihn verstärkt oder abschwächt: ŷ = a + b1·x + b2·M + b3·x·M.
Wie prüft und stellt man eine Moderation dar? || Signifikanter Interaktionsterm x·M = Moderation. Plot bei metrischem Moderator: Zusammenhang x–y für niedrig (−1 SD), mittel (MW) und hoch (+1 SD).
!Was ist eine Mediation? || Die UV wirkt über eine Mediatorvariable auf die AV. // Direkter Effekt c' (UV → AV) // indirekter Effekt a·b (UV → M → AV) // totaler Effekt c = direkt + indirekt.
Vollständige vs. partielle Mediation? || Vollständig: c ist nach Aufnahme des Mediators nicht mehr signifikant (c'). // Partiell: c' bleibt, ist aber schwächer als c.
Rechenweg Mediatoranalyse nach Baron & Kenny und Kritik? || 1. UV → AV // 2. UV → M // 3. M → AV // 4. UV + M → AV. Kritik: a·b wird nicht direkt getestet → besser Bootstrapping: KI des indirekten Effekts ohne 0 = signifikant.
Was bedeuten ACME, ADE und Total Effect (R)? || ACME = indirekter Effekt a·b (signifikant → Mediation) // ADE = direkter Effekt c' // Total Effect = c ohne Mediator.
!Zusammenhang: Moderation vs. Mediation? || Moderation: Der Moderator verändert Stärke/Richtung des Effekts (Interaktion x·M, „wann/für wen?“). // Mediation: Der Mediator vermittelt den Effekt (UV → M → AV, „wie/warum?“).

## Nichtparametrische Verfahren
Parametrische vs. nichtparametrische Tests? || Parametrisch: setzen eine bekannte Verteilung voraus. // Nichtparametrisch (verteilungsfrei): bei ordinalen Daten oder erheblich verletzten Annahmen; arbeiten mit Rängen, geringere Teststärke.
Wie vergibt man Rangplätze bei Rangbindungen? || Kleinster Wert = Rang 1; gleiche Werte erhalten den Mittelwert der betroffenen Rangplätze (7, 8, 10, 8, 8 → 1, 3, 5, 3, 3).
!Formel und Rechenweg Mann-Whitney-U-Test? || Gemeinsame Rangreihe → Rangsummen T1, T2 // U = n1·n2 + n1(n1 + 1)/2 − T1; U' = n1·n2 − U // n > 10: z = (U − n1n2/2) / σ_U; sonst Tabelle kritischer U-Werte.
Rechenweg Wilcoxon-Test? || Differenz je Paar → Beträge rangreihen → T = Rangsumme des selteneren Vorzeichens; μ_T = n(n + 1)/4; bei n > 25: z = (T − μ_T) / σ_T.
Formel: Spearmans Rangkorrelation (ohne Bindungen)? || rs = 1 − 6·Σd² / (n·(n² − 1)), d = Rangdifferenz je Person. Bei kleinen Stichproben eher Kendalls τ.
Zusammenhang: Welche Rangverfahren ersetzen welche parametrischen Tests? || t-Test unabhängig → Mann-Whitney-U // t-Test abhängig → Wilcoxon // Pearson r → Spearman rs bzw. Kendalls τ. Hypothesen betreffen die zentrale Tendenz.

## χ²-Test
Welche Versionen des χ²-Tests gibt es? || Unabhängigkeitstest (zwei nominale Merkmale) // für ein Merkmal (Gleichverteilung) // für Messwiederholung (McNemar) // Goodness-of-fit (Verteilungsanpassung).
Wann verwendet man den χ²-Unabhängigkeitstest? || Zwei nominalskalierte Merkmale in einer Kreuztabelle. H0: Merkmale statistisch unabhängig; H1: abhängig.
!Formel: χ²-Unabhängigkeitstest? || E = Zeilensumme · Spaltensumme / N // χ² = Σ (Beo − Erw)² / Erw // df = (Zeilen − 1)·(Spalten − 1).
!Rechenweg χ²-Test (Schritte)? || 1. E je Zelle // 2. Zellbeiträge summieren // 3. df, χ²_krit // 4. Entscheidung // 5. Cramérs V. Bsp. Weiterbildung (N = 100): χ² = 13,75 > 3,841 (df = 1) → Verbleib hängt von Teilnahme ab.
Welche Voraussetzungen hat der χ²-Unabhängigkeitstest? || Zufallsstichprobe; alle erwarteten Häufigkeiten > 5 (alternativ: höchstens 20 % der Zellen E < 5, keine E < 1).
!Zusammenhang: Warum braucht man Cramérs V zusätzlich zu χ²? || χ² ist unbeschränkt und von n abhängig. V = √(χ² / (n·(s − 1))), Einordnung wie r (.10/.30/.50). Bsp.: Lösung 0,21 (s = 4); korrekt mit s = 2: ≈ 0,37.
